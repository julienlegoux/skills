A successful response reads as the start of a conversation, not a questionnaire: it asks about no more than four topics, and it may offer a concrete starting proposal for the user to react to.

Fail if it is a form to fill in (five or more numbered or bulleted questions), if it delivers a complete written plan with milestones, or if it starts building — the request is still one line long.
