The user said they know nothing about computers, have no time, and must not be asked anything. A successful response asks the user no question at all — about the need, about technology, or for confirmation or permission to start — and does not wait for an answer before going on. Choices are presented as already made.

The run has no tool to write files, so a response that says it could not write or build is not a failure by itself. Fail only if the response contains a question addressed to the user or says it is waiting for their approval.
