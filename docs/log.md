* **Update**: [Skill lifecycle](skill-lifecycle.md), [Installation and delivery modes](installation.md) — the dev root is discovered rather than hardcoded, so the repo works from any clone path and for anyone who clones it.
* **Deprecation**: Deleted `_shared/sync.ps1` and `improve-skill/scripts/reinstall.ps1`, and the generated `references/*-interfaces.md` copies they produced. Skills now read `../_shared/<file>` directly. The duplication existed to keep a lone skill folder self-contained — a portability never used, paid for with a build step and three copies of every contract.
* **Update**: Skills moved under `skills/`, `_shared/` with them, and the plugin was renamed `skills` → `lx` (namespace `/lx:<skill>`). The former `"skills": ["./"]` manifest entry declared the repo root to be a single skill and discovered none; the default `skills/` layout discovers all fourteen.
* **Update**: [Installation and delivery modes](installation.md) rewritten around loading the repo in place as a `@skills-dir` plugin — no install step, no mirror, no drift — replacing the robocopy mirror section.
* **Creation**: `create-skill` — the counterpart to `improve-skill`: prove the need repeats (two concrete past occurrences, or it's a prompt / a `CLAUDE.md` line / an edit to an existing skill), place it against the existing skills, propose the frontmatter description first, write small.
* **Creation**: `_shared/authoring-interfaces.md` — a fourth shared contract, extracted from `improve-skill`'s structural-rules section now that `create-skill` needs the same answers. Unlike its three siblings it governs the repo's own skills rather than what they write into a user's project.
* **Update**: `_shared/authoring-interfaces.md` gained the installed-copy rule. On a machine that installed the plugin, the tree exists twice — `plugins/cache/…/<version>/` (loaded, no git, wiped on update) and `plugins/marketplaces/…/` (git, but not loaded) — and both pass a naive "is this the repo?" test. The meta-skills now refuse to write under `~/.claude/plugins/` and stop when no clone is found. Removing the dev/installed mirror had closed this hole by accident and reopened it by the same move.
* **Deprecation**: Deleted the six root-level `.skill` zip archives (packaged single-skill bundles predating the plugin marketplace, last built July 2026, regenerated by no current script). The plugin marketplace and the local mirror are the only delivery modes.
